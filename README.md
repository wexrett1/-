# Маршрут ПДД

Telegram Mini App для подготовки к теории на категории A и B. Полный комплект из 40 билетов и 800 вопросов, короткие занятия по темам, работа над ошибками и пробный экзамен. У каждого вопроса есть пояснение. Во время тренировки оно открывается после выбора, в экзамене — в разборе результатов. Прогресс сохраняется на устройстве. Pro включает план к дате экзамена, подборку слабых тем, интервальные повторы и скрытие рекламы.

## Локальный запуск

В корне проекта выполните `python -m http.server 8080 --directory dist` и откройте http://localhost:8080. В браузере работают все бесплатные режимы. Для подписки используется сервер Telegram Stars, для показов нужен активный блок РСЯ.

## Запуск в Telegram

Приложение включает Cloudflare Worker, D1 для платежей и статические файлы в `dist`. Для публичного запуска:

1. Создайте бота в @BotFather.
2. В каталоге проекта выполните `npx wrangler login` и `npx wrangler d1 create pdd-marshrut`. Впишите возвращённый `database_id` в `wrangler.jsonc`, а в `SUPPORT_CONTACT` — публичный контакт для вопросов об оплате.
3. Выполните `npx wrangler d1 execute pdd-marshrut --remote --file schema.sql` и `npx wrangler deploy`.
4. Добавьте секреты командами `npx wrangler secret put BOT_TOKEN` и `npx wrangler secret put WEBHOOK_SECRET`. Первый выдаёт BotFather, второй сгенерируйте сами как случайную строку из латинских букв, цифр, дефисов или подчёркиваний. Храните их в настройках хостинга.
5. Настройте Telegram `setWebhook` с адресом `https://ВАШ-ДОМЕН/api/telegram`, тем же `secret_token` и `allowed_updates: ["message","pre_checkout_query"]`. Скрипт `node tools/set-webhook.mjs https://ВАШ-ДОМЕН` читает `BOT_TOKEN` и `WEBHOOK_SECRET` из переменных окружения текущей сессии.
6. В @BotFather укажите корневой HTTPS-адрес в настройках Main Mini App. При изменении адреса обновите webhook. Оплата стоит 199 Stars за 30 дней с автопродлением. Проверьте покупку и возврат в тестовой среде Telegram перед приёмом реальных платежей.

[Настройка Mini Apps](https://core.telegram.org/bots/webapps) · [Stars](https://core.telegram.org/bots/payments-stars) · [Cloudflare D1](https://developers.cloudflare.com/d1/get-started/)

## Реклама

В кабинете РСЯ добавьте HTTPS-домен в разделе «Реклама на сайтах», пройдите модерацию и создайте адаптивный RTB-баннер. Впишите его ID (`R-A-…`) в `RSY_BLOCK_ID` и повторите `npx wrangler deploy`. Код загружает рекламу только на экране результатов для бесплатных пользователей, максимум один успешный показ в день на устройство.

[Подключение Mini Apps к РСЯ](https://yandex.ru/support/partner/ru/messengers/faq)

## Билеты

База импортирована из [etspring/pdd_russia](https://github.com/etspring/pdd_russia/tree/fa37933b2ea686db47c64401773e53f6775b8df0) (редакция 2026.q3.0 от 2 сентября 2026 года). Файл `dist/data/tickets.json` содержит 40 × 20 вопросов категории A/B. Перед коммерческим запуском сверьте редакцию и происхождение иллюстраций с первоисточником. В выгрузке отсутствует отдельный файл лицензии. Учебные пояснения к каждому вопросу взяты из поля `answer_tip` той же выгрузки. Для нескольких вопросов добавлены редакционные уточнения. Перед коммерческой публикацией отдельно проверьте условия использования пояснений и актуальность приведённых норм.

Для обновления запустите `python tools/import.py PATH_TO_DATASET` из каталога проекта. Скрипт проверяет полноту комплекта и однозначность правильных ответов.
